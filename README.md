# Jeffreyyao Tap

## How do I install these formulae?

`brew install jeffreyyao/tap/<formula>`

Or `brew tap jeffreyyao/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jeffreyyao/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
